# 2. Decide

Before anything gets built: is this a job for AI, which kind, how could it fail, and how much should it be trusted to do alone?

Read in this order:

1. **[Should this task use AI, and which kind?](should-this-task-use-ai.md)** (4 min): Decision tree: should this task use AI at all, and if so which kind?
2. **[AI intake checklist](ai-intake-checklist.md)** (10 min): The 12 questions to ask when someone proposes an AI idea, and what good answers look like.
3. **[Where should AI go in our product or operations first?](where-ai-goes-first.md)** (5 min): Leadership memo: where AI should go first in a product or in operations.
4. **[AI feature spec template](ai-feature-spec.md)** (5 min): A fill-in template for proposing an AI feature, with why each section matters.
5. **[AI failure modes: a pre-mortem checklist](ai-failure-modes-premortem.md)** (10 min): How AI projects actually went wrong, as a 30-minute pre-mortem with a tick-list.
6. **[How much should an agent be trusted to do on its own?](how-much-autonomy-for-an-agent.md)** (5 min): Decision tree: how much an AI agent should be trusted to do on its own, one kind of action at a time.
