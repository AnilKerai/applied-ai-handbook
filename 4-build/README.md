# 4. Build

How to build AI features well: proven patterns, how to test them, how developers should work with coding agents, and two talks you can give to engineers.

Read in this order:

1. **[AI pattern catalogue](ai-pattern-catalogue.md)** (15 min): Ways to build AI features seen in practice, each with when to use it, when not to and the pitfalls.
2. **[Evals playbook](evals-playbook.md)** (15 min): How to test whether an AI feature works (evals), from building the test set to the statistics.
3. **[Working with coding agents](working-with-coding-agents.md)** (15 min): The day-to-day guide for developers using AI coding agents.
4. **[Talk: working with coding agents](talk-working-with-coding-agents.md)** (10 min): Session 1 of two talks for engineers: an 11-slide talk (outline and speaker notes) on working with coding agents, from checking their work to earning autonomy. The slides are the .pptx alongside.
5. **[Talk: building AI features](talk-building-ai-features.md)** (10 min): Session 2 of two talks for engineers: a 12-slide talk (outline and speaker notes) on building AI features, from a replaceable model to evals before launch. The slides are the .pptx alongside.
6. **[Building AI features in .NET](dotnet-ai-engineering-guide.md)** (10 min): The .NET 11 stack and practices I recommend for AI features.
