# 3. Engineer

The disciplines under every AI system: prompt, context, harness, loop and eval engineering, how they fit together, when they arrived, and first-hand lessons from building them.

Read in this order:

1. **[Prompt engineering](prompt-engineering.md)** (4 min): What prompt engineering is, when it arrived, and the principles that still hold.
2. **[Context engineering](context-engineering.md)** (4 min): What context engineering is: deciding what the model sees at each step, and the principles for doing it well.
3. **[Loop engineering](loop-engineering.md)** (4 min): What loop engineering is: running an agent many times and improving it from one run to the next.
4. **[Eval engineering](eval-engineering.md)** (4 min): What eval engineering is: measuring AI runs so changes can be judged, with a pointer to the evals playbook for the practice.
5. **[Multi-agent orchestration](multi-agent-orchestration.md)** (4 min): How several agents are connected and coordinated, and the principles for when and how to do it.
