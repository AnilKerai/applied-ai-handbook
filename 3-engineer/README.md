# 3. Engineer

The disciplines under every AI system: prompt, context, harness, loop and eval engineering, how they fit together, when they arrived, and first-hand lessons from building them.

Read in this order:

1. **[The big picture](the-big-picture.md)** (5 min): A map of the engineering disciplines around a model, what each one is for, and where each part of this handbook sits on it.
2. **[How the ideas arrived](how-the-ideas-arrived.md)** (5 min): A timeline of when each engineering idea was named or caught on, with my own path through them alongside.
3. **[Prompt engineering](prompt-engineering.md)** (4 min): What prompt engineering is, why I now treat it as part of context engineering, and the principles that still hold.
4. **[Context engineering](context-engineering.md)** (4 min): What context engineering is: deciding what the model sees at each step, and the principles for doing it well.
5. **[Harness engineering](harness-engineering.md)** (10 min): The deep page: the code around a model that makes one run reliable, from budgets and stopping rules to structured output and prompt-injection defences.
6. **[Loop engineering](loop-engineering.md)** (4 min): What loop engineering is: running an agent many times and improving it from one run to the next.
7. **[Eval engineering](eval-engineering.md)** (4 min): What eval engineering is: measuring AI runs so changes can be judged, with a pointer to the evals playbook for the practice.
8. **[Multi-agent orchestration](multi-agent-orchestration.md)** (4 min): How several agents are connected and coordinated, and the principles for when and how to do it.
9. **[Lessons from my harness](lessons-from-my-harness.md)** (5 min): First-person lessons from building an agent harness: what held up, what didn't, and why.
10. **[Lessons from my evals framework](lessons-from-my-evals-framework.md)** (5 min): First-person lessons from building an evals framework, written as general principles.
11. **[Lessons from running agent squads](lessons-from-running-agent-squads.md)** (5 min): First-person lessons from running teams of AI agents that work together on real tasks.
